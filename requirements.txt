# Hugging Face Space dependencies.
#
# A deliberate SUBSET of services/ai-service/requirements.txt, not an "-r" include:
# Hugging Face installs this file in a build stage that holds it alone, so a
# relative include resolves to nothing and the build dies before installing.
#
# sentence-transformers is excluded. It pulls torch and transformers, 520MB
# installed, which is the bulk of the image and more than a free Space build wants
# to carry. evaluate.py imports it lazily and falls back cleanly without it; it
# only feeds the offline heuristics used when the LLM judge is unreachable, and the
# judge is the normal path. Add it back if the Space is upgraded.
#
# gradio is absent because the Space pre-installs it and pins the version through
# sdk_version in README.md.
#
# scripts/deploy-hf-space.sh checks this stays a subset of the service list.

# Unpinned on purpose: the Space force-installs gradio, which requires a much
# newer starlette than fastapi 0.115 allows, and the pin made the build
# unresolvable. The service uses only long-stable FastAPI APIs.
fastapi>=0.115
uvicorn[standard]>=0.34
python-dotenv==1.0.1
python-multipart==0.0.20
numpy==2.2.1
# Eye-contact analysis (analyze-video): face mesh + iris landmarks
